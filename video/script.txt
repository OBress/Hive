[hook]
Software is now built by people and AI agents, side by side.

[problem]
But every agent works alone: its own tab, its own chat, its own branch. Nobody sees what the others are doing. Decisions get lost, and work collides.

[intro +0.9]
Hive fixes that: one live task graph where your whole team and its agents build together.

[plan]
Maya types one message: build a URL shortener with click stats. The Planner splits it into tasks, and agents build each one in its own sandbox, streaming every edit and test live.

[steer]
Sam steers an agent mid-run. Priya takes over a task, fixes an edge case by hand, and hands it back.

[stale]
Then Maya changes a spec: count clicks per day, not total. Hive marks that task stale, stops it, and rebuilds only that task. Everything that already passed stays put.

[conflict]
When two agents touch the same file, Hive proposes an AI merge and applies it only if the tests pass. Otherwise, a person picks.

[memory]
Every change is recorded. Ask the Planner why short codes are six characters, and it answers from the log, citing the decisions.

[ship]
When every test is green, one click approves and pushes the repo to GitHub.

[outro +2.6]
Hive. Humans and agents, one graph.
